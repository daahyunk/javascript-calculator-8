# javascript-calculator-precourse

## 구현할 기능 목록

### 1. 입력 처리
- [x] 콘솔을 통해 문자열을 입력받는다.
- [x] 입력이 비어 있거나 `""`인 경우 결과는 0을 반환한다.
- [ ] 입력이 `null`, `undefined`, 혹은 문자열이 아닌 경우 에러를 발생시킨다.
- [ ] 입력 문자열에 공백이 포함되어 있으면 제거하고 처리한다.
- [ ] 숫자나 구분자가 하나도 없는 문자열 입력 시 에러를 발생시킨다.

---

### 2. 구분자 처리
- [x] 기본 구분자 `,`(쉼표)와 `:`(콜론)을 기준으로 숫자를 분리한다.
  - 예) `"1,2:3"` → `[1, 2, 3]`
- [ ] 커스텀 구분자를 지원한다.
  - 문자열이 `"//[구분자]\n"` 형태로 시작하는 경우, 지정된 구분자를 사용한다.
  - 예) `"//;\n1;2;3"` → `[1, 2, 3]`
- [ ] 구분자가 여러 개 섞여 있을 경우 모두 올바르게 분리되어야 한다.
- [ ] 커스텀 구분자 형식이 `"//[구분자]\n"` 형태가 아닐 경우 에러를 발생시킨다.
- [ ] 구분자 뒤에 숫자가 없거나, 구분자가 연속되어 숫자가 비어 있을 경우 에러를 발생시킨다.
- [ ] 허용되지 않은 특수문자를 구분자로 지정한 경우 에러를 발생시킨다.

---

### 3. 계산 기능
- [ ] 분리된 문자열을 숫자로 변환한다.
- [ ] 변환된 숫자들의 총합을 계산하여 반환한다.
- [ ] 결과를 `"결과 : {sum}"` 형식으로 출력한다.
- [ ] 계산 결과가 NaN인 경우 에러를 발생시킨다.

---

### 4. 예외 처리
#### 입력 관련
- [ ] 입력값이 존재하지 않는 경우 → `"[ERROR] 입력값이 존재하지 않습니다."`
- [ ] 문자열이지만 숫자나 구분자가 없는 경우 → `"[ERROR] 숫자를 포함하지 않은 입력입니다."`
- [ ] 허용되지 않은 타입(객체, 배열 등)을 입력한 경우 → `"[ERROR] 올바른 문자열을 입력해야 합니다."`

#### 구분자 관련
- [ ] 잘못된 커스텀 구분자 형식 → `"[ERROR] 구분자 형식이 잘못되었습니다."`
- [ ] 구분자 뒤에 숫자가 없는 경우 → `"[ERROR] 구분자 이후에 숫자가 없습니다."`
- [ ] 구분자가 연속되어 있는 경우 → `"[ERROR] 구분자 사이에 숫자가 없습니다."`
- [ ] 허용되지 않은 특수문자 구분자 → `"[ERROR] 허용되지 않은 구분자입니다."`

#### 숫자 관련
- [ ] 숫자가 아닌 값이 포함된 경우 → `"[ERROR] 숫자가 아닌 값이 포함되어 있습니다."`
- [ ] 음수가 포함된 경우 → `"[ERROR] 음수는 입력할 수 없습니다."`
- [ ] 숫자 변환 실패(NaN) → `"[ERROR] 잘못된 숫자 형식이 포함되어 있습니다."`
- [ ] 매우 큰 수(`Number.MAX_SAFE_INTEGER` 초과) → `"[ERROR] 허용 범위를 초과한 숫자입니다."`

#### 출력 관련
- [ ] 계산 결과가 유효하지 않은 경우(NaN 등) → `"[ERROR] 계산 결과가 유효하지 않습니다."`
- [ ] 콘솔 출력 중 에러 발생 시 → `"[ERROR] 결과 출력 중 문제가 발생했습니다."`

---

### 5. 프로그램 동작 과정
- [x] 프로그램 시작 시 `"덧셈할 문자열을 입력해 주세요."` 문구를 출력한다.
- [ ] 사용자가 입력한 문자열을 기반으로 계산을 수행한다.
- [ ] 결과를 `"결과 : {sum}"` 형태로 콘솔에 출력한다.
- [ ] 에러가 발생하면 `[ERROR]`로 시작하는 메시지를 출력하고 프로그램을 종료한다.
